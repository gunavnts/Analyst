# Analyst

A collection of data analytics projects, Power BI dashboards, and Python/Jupyter Notebook exercises focused on reporting, data preparation, healthcare analytics, web scraping, elections, and electric vehicles.

## Repository Contents

### Power BI Dashboards

| Project | Description | Assets |
|---|---|---|
| **US Electric Vehicle Market Analysis** | Explores electric-vehicle adoption across the United States, including EV, PHEV, and hybrid categories, state-level comparisons, and alternative-fuel vehicle trends. | [`US_Vehicle.pbix`](PowerBI/US_Vehicle.pbix) · [`US Electric Vehicle.jpg`](PowerBI/US%20Electric%20Vehicle.jpg) |
| **Patient Profile & Diagnosis Dashboard** | Healthcare dashboard for analyzing patient profiles, visits, diagnoses, age groups, sex, and CPT-code utilization. | [`Patient Profile & Diagnosis Dashboard.pbix`](PowerBI/Patient%20Profile%20%26%20Diagnosis%20Dashboard.pbix) · [`Patient_Profie & Diagnosis_New.png`](PowerBI/Patient_Profie%20%26%20Diagnosis_New.png) |
| **Tamil Nadu Election 2026 Dashboard** | Election analysis dashboard covering constituencies, candidates, parties, and voting results with interactive drill-downs. | [`Tamilnadu_election2026.pbix`](PowerBI/Tamilnadu_election2026.pbix) · [`Tamilnadu_election2026Srcn.png`](PowerBI/Tamilnadu_election2026Srcn.png) |
| **Participants Dashboard** | Power BI report asset for participant-related analytics and reporting. | [`Data_Participants.pbix`](PowerBI/Data_Participants.pbix) |

### Python and Jupyter Notebook Projects

| Project | Description | Asset |
|---|---|---|
| **Patient Profile & Diagnosis Trends** | Analyzes 200 healthcare visits using Python, Pandas, Matplotlib, and Seaborn. The notebook validates the data, creates age bands, counts diagnoses, identifies the top 10 ICD codes, and examines diagnosis patterns by age group and sex. | [`Patient Profile & Diagnosis Trends.ipynb`](Python/Project/Patient%20Profile%20%26%20Diagnosis%20Trends.ipynb) |
| **Web Scraping: World Population Data** | Uses `requests` and `BeautifulSoup` to scrape the Worldometer population-by-country table, extract column names and country-level records, and load the results into a Pandas DataFrame. | [`=Scrapping real from real website.ipynb`](Python/Project/%3DScrapping%20real%20from%20real%20website.ipynb) |
| **Data Cleaning and Preprocessing** | Demonstrates practical data-cleaning techniques, including duplicate detection and removal, phone-number standardization, and normalization of inconsistent Yes/No values. | [`DataCleaning_Preprocessing.ipynb`](Python/Project/DataCleaning_Preprocessing.ipynb) |

## Skills Demonstrated

- **Python:** Pandas, NumPy, Matplotlib, Seaborn, Requests, BeautifulSoup
- **Business Intelligence:** Microsoft Power BI, dashboard design, drill-downs, filtering, and KPI reporting
- **Data Preparation:** Duplicate handling, text normalization, phone-number formatting, validation, and preprocessing
- **Analytics:** Trend analysis, demographic segmentation, diagnosis-frequency analysis, election reporting, and vehicle-market analysis
- **Data Sources:** Structured datasets, HTML tables, healthcare visit records, election data, and vehicle-registration data
